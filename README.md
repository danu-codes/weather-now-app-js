Weather Now ☀️
=====================
Weather Now is a simple and responsive web app that lets you check the current weather, forecast, and detailed weather information for any city using the OpenWeatherMap API.

Features
=====================
- Display current temperature, weather condition, humidity, wind, and "feels like" temperature.
- Show a 7-day forecast with weather icons.
- Automatically updates the background color based on the current weather.
- Search for any city worldwide.

Technologies Used
=====================
- HTML
- CSS
- JavaScript
- OpenWeatherMap API
